vega-webgpu

Version 2.0.4

A packaging patch for 2.0.3: nothing the package installs is commonjs any more. The renderer is the same as 2.0.3.

vega-webgpu-renderer.js vega-webgpu-renderer.min.js ESM build Try it Render gallery

Load it

This build targets Vega 6. Loaded next to a different major version of Vega it throws when it registers itself. 

<script src="https://cdn.jsdelivr.net/npm/vega@6/build/vega.min.js"></script>
<script src="https://vega.github.io/vega-webgpu/releases/2_0_4/vega-webgpu-renderer.min.js"></script>

Fixes

  • The esm build bundles adaptive-bezier-curve, simplify-path, triangulate-contours and extrude-polyline, where it left them as bare imports: they are commonjs, so a consumer serving the build as untransformed esm could not resolve them and had to pre-bundle them by name
  • The four helpers move to devDependencies, where installing the package pulled them in as runtime dependencies although both builds already bundle them
  • d3-shape moves to devDependencies too, where it was declared a runtime dependency although both builds bundle it. An install still has it, because vega-scenegraph depends on it
